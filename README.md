### Assignment Description

Completed a comprehensive Software Testing assignment for the **NOVA Team Productivity Platform**, covering the complete QA lifecycle from requirement analysis to release readiness.

The assignment includes **50 test scenarios, 30 detailed test cases, Requirement Traceability Matrix (RTM), smoke and regression test suites, API testing using Postman, basic automation testing using Playwright, compatibility testing, bug reports, and a final QA report**.

The testing approach covers **functional, negative, exploratory, UI, usability, API, regression, cross-browser and mobile testing**. The assignment also demonstrates defect identification and reporting, test documentation, risk assessment, and release recommendation.

The objective was to demonstrate the ability to **Understand → Plan → Test → Discover → Report → Retest → Automate → Assess Risk → Recommend Release**.
